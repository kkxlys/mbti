# 高考后抽象人格测试题库

文件：`data/question-bank-gaokao-absurd-48.json`

这是一套原创题库，共48题，风格是沙雕、二次元、荒诞校园、高考志愿。它借用了16型人格常见的四维度计分结构，但没有使用官方MBTI题库原题，也不建议在产品中宣称“官方MBTI测评”。

## 题库结构

- `EI`：能量来源，外放充能 E / 内置电池 I
- `SN`：信息处理，现实雷达 S / 脑洞跃迁 N
- `TF`：决策方式，逻辑拆解 T / 情绪共振 F
- `JP`：行动节奏，进度条玩家 J / 随机应变玩家 P

每个维度12题，总计48题。每题4个选项，其中两个偏向维度左侧，两个偏向维度右侧。强倾向记2分，弱倾向记1分。

## 计分方式

后端保存用户每题选择的 `questionId` 和 `optionId`，然后读取对应选项的 `scores` 字段累加。

示例：

```json
{
  "questionId": "GQ001",
  "optionId": "A",
  "scores": {
    "E": 2
  }
}
```

维度结果计算：

```text
E_percent = E / (E + I)
I_percent = I / (E + I)
结果字母 = E >= I ? "E" : "I"
```

其他三个维度同理。最终类型由四个结果字母拼接得到，例如 `ENFP`。

建议报告不要只展示四个字母，还要展示强度：

```json
{
  "type": "ENFP",
  "scores": {
    "E": 17,
    "I": 8,
    "S": 9,
    "N": 16,
    "T": 10,
    "F": 15,
    "J": 7,
    "P": 18
  },
  "strength": {
    "EI": {
      "winner": "E",
      "percent": 0.68
    }
  }
}
```

## 产品建议

支付前可以展示模糊预览：

- 你的志愿人格报告已生成
- 已识别学习风格、专业倾向、风险偏好
- 支付后解锁完整人格解释和专业推荐

支付成功后再把以下内容交给AI：

- 高考成绩、位次、省份、选科
- 48题选择结果
- 四维度原始分和百分比
- 用户偏好：城市、预算、兴趣、就业优先级
- 可选专业库候选项

AI只负责生成解释和推荐理由，不建议让AI重新计算人格分数。

## 命名建议

可用：

- 16型志愿人格
- 异世界专业匹配测试

避免：

- 官方MBTI测试
- MBTI标准题库
